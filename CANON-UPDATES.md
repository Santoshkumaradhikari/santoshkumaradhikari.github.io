# The Investor's Canon — chapter-by-chapter update system

**Edit one chapter → push → the live site updates itself.**
Prev/next nav, `dateModified`, the index TOC, chapter counts, `feed.xml` (new)
and `investors-canon/sitemap.xml` (new) are all regenerated by `build.py`,
which runs automatically on every push via `.github/workflows/build-canon.yml`.

```
You edit investors-canon/chapters/ch-14-ipos.html
        │  git push (or edit in the browser)
        ▼
Canon Build workflow runs python3 build.py
        • refreshes prev/next nav in every chapter (from chapters.yml order)
        • bumps dateModified ONLY where body text actually changed
        • regenerates the index TOC, hero counts and Book JSON-LD
        • rebuilds investors-canon/feed.xml + investors-canon/sitemap.xml
        • commits the result ("Auto: canon build …") → Pages redeploys
        ▼
santoshkumaradhikari.com.np updated in ~1 minute
```

## What was added to this repo

| File | Purpose |
|---|---|
| `build.py` | The build engine (Python standard library only) |
| `chapters.yml` | The book's table of contents — titles, numbers, order, volumes/parts |
| `.github/workflows/build-canon.yml` | Runs the build on every push and commits the result |
| `investors-canon/feed.xml` | **New:** Atom feed of recently revised chapters |
| `investors-canon/sitemap.xml` | **New:** fresh `<lastmod>` for every book page |
| `.canon-cache.json` | Build state (content hashes) — **must be committed** |
| `robots.txt` | One line added: points to the new book sitemap |

Nothing else in the repo was touched: your prose, pages, styles and the
Daily Market Data workflow are untouched (that workflow's bot pushes never
trigger this build, and vice versa — no loops).

## ✏️ Updating a chapter (the everyday flow)

**In the browser (no tools needed):**
1. `investors-canon/chapters/` → open the chapter → pencil icon
2. Edit the prose between the lesson headings
3. Commit — e.g. `ch14: clarify allotment blocking`
4. Done. The Action rebuilds everything; the site updates in ~1 minute.

**On your computer:**
```bash
# edit the chapter file, then:
git add -A && git commit -m "ch14: clarify allotment blocking" && git push
```

Run `python3 build.py` first if you want to preview the regenerated files
locally — but it's optional; the Action always runs it for you.

## ➕ Adding / renaming / reordering chapters

Order of the book = order of entries in `chapters.yml`. To add chapter 119:

1. Create `investors-canon/chapters/ch-119-your-chapter.html`
   (copy any existing chapter as the template).
2. Add to `chapters.yml` in position:

   ```yaml
             chapters:
               - slug: "ch-119-your-chapter.html"
                 num: "119"
                 title: "Your Chapter Title"
                 minutes: 20
                 date_published: "2026-09-07"
   ```

3. Push. Index TOC, neighbouring chapters' prev/next links, feeds, sitemap and
   the "121 chapters in all" counts all update automatically.

Rename a file → update its `slug:`. Move a chapter → move its block.
Useful commands:

```bash
python3 build.py --extract           # rebuild chapters.yml from the current index
python3 build.py --recompute-times   # recompute "~N min" reading times
python3 build.py --date 2026-09-14   # force a specific bump date for this run
```

## First-time integration (one-off)

Push these files to `main`:

- New: `build.py`, `chapters.yml`, `.canon-cache.json`,
  `.github/workflows/build-canon.yml`
- Modified: `robots.txt` and all of `investors-canon/` (feed links in every
  page, 22 chapters' nav apostrophes/ampersands normalised, book index schema
  refreshed)
- New pages: `investors-canon/feed.xml`, `investors-canon/sitemap.xml`

Easiest path: GitHub → **Add file → Upload files** → drag in the contents of
`canon-kit/` (the upload preserves folders) → commit. Or `git`:
`git add -A && git commit -m "Canon: chapter-by-chapter build system" && git push`.

Then watch the **Actions** tab: "Canon Build" runs, commits its output, and
Pages redeploys. Verify afterwards:

- `https://santoshkumaradhikari.com.np/investors-canon/feed.xml`
- `https://santoshkumaradhikari.com.np/investors-canon/sitemap.xml`

Optional later cleanup: the root `sitemap.xml` still lists all 121 chapter URLs
(duplicates across sitemaps are allowed). You can prune them from the root
file any time — the book sitemap now owns those URLs.

## Good to know

- **The build never touches your prose.** It only rewrites the
  `chapter-nav` block, the JSON-LD dates, the head feed link, and generated
  index blocks.
- **`dateModified` only moves when text changes** — verified by content hash,
  so redeploys don't fake freshness.
- **Fix nav/order problems in `chapters.yml`**, never by hand-editing chapter
  links — the build will overwrite them on the next run.
- **Reset everything:** `rm .canon-cache.json chapters.yml && python3 build.py --extract && python3 build.py`.
- **Local preview:** `python3 -m http.server 8000` from the repo root, then
  open `http://localhost:8000/investors-canon/`.
